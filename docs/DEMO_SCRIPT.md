# Demo script

Target duration: 2 minutes 50 seconds. Keep the final upload below 3 minutes.

## 0:00-0:12

Picture: Title, then the live app at the hero and native status badge.

Voiceover: "Seven Transects is a playable WebMCP test for supervising a browser agent. We have seven scans to map half of this island at 88 percent precision."

## 0:12-0:32

Picture: Open ChatGPT Site tools and show all six names. Return to the app with `WebMCP live / 6 tools` visible.

Voiceover: "The page registers six tools directly with `document.modelContext`. ChatGPT discovers them from the open page. It does not need to guess which grid buttons spend a scan, stage a patch, or request a decision."

## 0:32-0:50

Picture: Send the copied mission. Show `get_expedition_state` and `inspect_chart` in ChatGPT and the visible trace.

Voiceover: "The first two calls read the objective, remaining budgets, committed marks, and previous handoffs. Tool results omit the truth map, the operation seed, and exact live precision."

## 0:50-1:14

Picture: The agent calls `survey_region` at row 6, column 6. Hold on the spent scan and exact cross.

Voiceover: "`survey_region` is a write. It spends one of seven charges and returns exact terrain along a narrow cross. The typed result updates the same chart the person is viewing."

## 1:14-1:42

Picture: The agent calls `propose_chart_patch`. Show the striped overlay, evidence labels, and pending review. Select **Accept verified**.

Voiceover: "The agent combines exact cells with a cautious inference, then stages a patch. It cannot commit the chart. I choose Accept verified, which keeps completed scan evidence and authorized human readings while leaving unsupported inference out. The provenance check also rejects an agent that labels an unsurveyed cell as exact."

## 1:42-2:08

Picture: Show `focus_human_attention`, the pinned coordinate, and the human terrain buttons. Choose the visible terrain. Then show the next `inspect_chart` call.

Voiceover: "For an uncertain diagonal, the agent calls `focus_human_attention`. I interpret the field layer and send one structured answer. `inspect_chart` gives that authorized answer back to the agent, so the handoff becomes part of the shared state."

## 2:08-2:26

Picture: Call `consult_compass`. Show the remaining check count and broad band.

Voiceover: "A safety check costs one of two consultations. It returns a broad precision band, not the correct cells, so the tool cannot be used as an answer oracle."

## 2:26-2:42

Picture: Two labeled jump cuts through later scans and human marks. End at 72 marked cells.

Voiceover: "Later turns repeat the same review loop. Exact scans cover 60 unique cells. Human readings and manual chart decisions fill the remaining gaps."

## 2:42-2:50

Picture: Select **Transmit chart**. Hold on the winning score, then show the live URL and repository URL.

Voiceover: "This run reaches the coverage and precision targets. The live app and full source are ready for judge testing."

## Production notes

- Record native discovery in ChatGPT's browser. Do not present local replay as native agent footage.
- Capture at 1920 by 1080 and 30 frames per second.
- Use hard cuts for later turns. Avoid speed ramps that make the trace unreadable.
- Keep narration near -16 LUFS with true peak below -1.5 dB.
- Export H.264 video with AAC audio and `faststart` enabled.
- Upload to YouTube as public or unlisted, then review the generated captions.
- Do not add music or third-party assets unless their use is licensed.
