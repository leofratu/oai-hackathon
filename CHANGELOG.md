# Changelog

## 1.0.0 - 2026-08-29

- Replaced the mapping game with Label Loop, an online support-ticket classifier.
- Added in-browser multinomial Naive Bayes with incremental count updates.
- Added entropy-ranked active learning, human-only labels, and a bounded review queue.
- Added a fixed holdout with accuracy, macro F1, per-class F1, confidence, and log loss.
- Added staged model configuration with human approval and a working review threshold.
- Registered seven WebMCP tools over the shared model state.
- Rebuilt the responsive UI as a training console with metrics, history, trace, and ledger.
- Replaced the automated tests, browser workflow, documentation, and demo plan.
